# WattHalo 设计基线

## 目标与原则

面向 Windows 桌面能耗监测。信息密度适中，优先可读性、实时数据的来源和状态、稳定的布局与直接操作；界面使用中性表面与青绿色点缀，不使用装饰性持续动画。核心任务可通过键盘完成，状态不能仅靠颜色表达。

## 主题与色彩

| 语义 | 深色 | 浅色 |
| --- | --- | --- |
| 背景 | `#151718` | `#F7F8F7` |
| 表面 | `#202324` | `#FFFFFF` |
| 正文 | `#F1F3F2` | `#1E2723` |
| 辅助文字 | `#B3BBB8` | `#52635C` |
| 强调 | `#6DE0B7` | `#087D60` |
| 分隔线 | `#404746` | `#C9D0CD` |
| 控件边框 | `#81918C` | `#71817B` |
| 强调色上的文字 | `#102019` | `#FFFFFF` |

主题支持深色、浅色和跟随 Windows 应用模式。启用 Windows 高对比度时使用系统窗口、文字、突出显示与禁用色，标准控件继续使用 WPF 的高对比模板。以上正文、辅助文字和强调色与相应表面的对比度均不低于 4.5:1；分隔线用于分组，交互焦点使用清晰的独立轮廓。

## 字体、间距和控件

- 常规正文 14 DIP，辅助文字至少 12 DIP；按 4 / 8 DIP 节奏安排间距。数值、价格和表格使用等宽数字以减少跳动。
- 标准控件使用 .NET 10 WPF Fluent 模板，保留键盘操作、系统语义和焦点提示；常用按钮至少 44 DIP 高。
- 控件、卡片和文本使用语义资源，主题变化时实时更新。数据图表保留空值与单位说明，不依赖颜色传达状态。
- 使用 Windows 原生窗口边框、系统菜单、最小化 / 最大化 / 关闭及贴靠行为，不绘制自定义标题栏。
- 导航采用克制的中性选中底色和强调色图标；设置按外观、采集、桌面组件、估算与电价以及更新分组，设置行的说明和操作左右对齐。
- 用电统计使用按日热力方块和可切换的趋势图。缺失值以线条或空白区分，明细表与键盘操作提供不依赖颜色的替代信息。

## 品牌

`src/WattMonitor.App/Assets/WattMonitor.svg` 是可替换的原始矢量标识；`Ui.BrandMark` 是用于 WPF 的同形矢量资源，`WattMonitor.ico` 为窗口、托盘和程序入口提供 16 / 20 / 24 / 32 / 40 / 48 / 64 / 256 像素版本。更换标识时保持三者一致。
